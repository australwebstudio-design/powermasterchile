# Power Master Chile

Versión limpia para GitHub y Vercel.

## Publicación

1. Sube el contenido de esta carpeta a la raíz del repositorio de GitHub.
2. Importa el repositorio desde Vercel.
3. Framework Preset: `Next.js`.
4. Root Directory: `./`.
5. Agrega en Vercel las variables `GROQ_API_KEY`, `GROQ_MODEL` y `NEXT_PUBLIC_TOW_PHONE`.
6. Presiona Deploy.

No escribas la clave real de Groq dentro de `.env.example` ni la subas a GitHub.

## Verificación local

```bash
npm install
npm run build
```
